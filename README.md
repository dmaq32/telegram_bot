# Telegram Subscription Bot

Telegram-бот на `aiogram` с продажей подписки, хранением покупок в SQLite и миграциями через Alembic.

## Что умеет бот

- регистрирует пользователя при первом `/start`;
- показывает главное меню и профиль пользователя;
- отображает историю покупок и общую сумму оплат;
- продаёт подписку на 1 месяц;
- активирует или продлевает подписку после успешной оплаты;
- отправляет администраторам уведомление о покупке;
- показывает в админ-панели базовую статистику по пользователям и покупкам.

## Оплата

Оплата реализована через `Telegram Payments`: бот отправляет invoice через `send_invoice`, а платёжный провайдер подключается через `PROVIDER_TOKEN`.

В текущей конфигурации используется провайдер ЮKassa, поэтому для работы нужен корректный `PROVIDER_TOKEN`.

После успешной оплаты бот:

- сохраняет покупку в таблицу `purchases`;
- продлевает `subscription_until` на 30 дней;
- отмечает пользователя как подписанного;
- отправляет уведомление администраторам.

## Структура

- `bot/` - исходный код бота;
- `bot/user/` - пользовательские сценарии, каталог и покупка подписки;
- `bot/admin/` - админ-панель и статистика;
- `bot/dao/` - модели, DAO и работа с БД;
- `bot/migration/` - миграции Alembic;
- `data/` - локальные данные SQLite;
- `requirements.txt` - зависимости проекта.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
alembic upgrade head
python -m bot.main
```

## Переменные окружения

- `BOT_TOKEN` - токен Telegram-бота;
- `ADMIN_IDS` - список Telegram ID администраторов;
- `PROVIDER_TOKEN` - токен платёжного провайдера для Telegram Payments;
- `CRYPTO_KEY` - служебный ключ проекта;
- `DB_URL` - строка подключения к базе данных.

## Данные

Бот хранит:

- пользователя в таблице `users`;
- историю оплат в таблице `purchases`;
- дату окончания подписки и статус подписки.

Для приватности в базе хранится не исходный `telegram_id`, а его хеш.
